# 🎬 Best Films — каталог IMDb Top 250

Консольное приложение для управления каталогом фильмов из рейтинга IMDb Top 250. Хранит данные в SQLite, поддерживает полный набор CRUD-операций и поиск.

## Возможности

- Импорт 250 фильмов из CSV в базу SQLite
- Поиск по жанру и по названию (частичное совпадение)
- Добавление нового фильма (ранг назначается автоматически)
- Редактирование и удаление записей
- Удаление фильмов старше заданного года (с подтверждением)
- Топ-5 фильмов по рейтингу (с учётом количества голосов)
- Подсчёт количества фильмов в базе

## Технологии

- **Python 3** — стандартная библиотека
- **sqlite3** — встроенная БД (без внешних зависимостей)
- Параметризованные SQL-запросы (защита от SQL-инъекций)

## Структура

```
best_films/
├── database.py           # Создание БД, импорт CSV
├── database_manager.py   # CRUD-операции и поиск
├── main.py               # Консольное меню
├── imdb_top_250.csv      # Исходные данные
├── imdb_top.db           # База SQLite (генерируется)
└── Description.txt        # Описание проверок
```

### Поля таблицы `films`

| Поле | Описание |
|------|----------|
| `rank` | Позиция в рейтинге (PRIMARY KEY) |
| `title` | Название |
| `year` | Год выпуска |
| `genre` | Жанр |
| `duration` | Длительность |
| `origin` | Страна |
| `director` | Режиссёр |
| `imdb_rating` | Рейтинг IMDb |
| `rating_count` | Количество голосов |
| `imdb_link` | Ссылка на IMDb |

## Запуск

```bash
# 1. Создать базу и импортировать данные
python database.py

# 2. Запустить приложение
python main.py
```

## Пример использования

После запуска `main.py` доступно меню:
- Поиск по жанру
- Удаление фильмов старше года
- Добавление фильма
- Подсчёт количества
- Топ-5 по рейтингу
- Поиск по названию
